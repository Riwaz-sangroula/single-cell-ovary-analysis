# Single-Cell Ovary Analysis

This project documents my ongoing single-cell RNA-seq analysis of ovarian samples using **R** and **Seurat**.

The goal of this project is to build a complete and reproducible workflow for processing, exploring, clustering, and interpreting single-cell transcriptomic data.

## Project Goals

- Import and inspect single-cell RNA-seq data
- Create Seurat objects
- Perform quality control
- Normalize gene-expression data
- Identify highly variable features
- Perform dimensionality reduction
- Cluster cells
- Visualize cell populations with UMAP
- Identify marker genes
- Interpret biologically meaningful cell populations

## Tools
